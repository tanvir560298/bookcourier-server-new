# BookCourier Server

Backend API server for BookCourier application.

## Live API

https://bookcourier-server-new.vercel.app

## Features

- MongoDB database
- Firebase admin authentication
- JWT protected routes
- Books API
- Orders API
- Users API
- Role based access

## Technologies

- Node.js
- Express.js
- MongoDB
- Firebase Admin
- Vercel

## Environment Variables

Create a `.env` file:

```env
PORT=5001
DB_USER=your-db-user
DB_PASS=your-db-password
```

## Run Locally

```bash
npm install
npm run dev
```
